# XIAO wireless prototype validation

The editable PCB is `001 PCB/KICAD/XIAO WIRELESS/TheEndgame2024_XIAO.kicad_pcb`. Its fabrication ZIP is `001 PCB/GERBER/XIAO WIRELESS/TheEndgame2024_XIAO_Choc_V1_V2_JLCPCB.zip`. These are a digitally checked prototype design; no physical board has been built or tested.

- **KiCad 10.0.6:** full-source DRC after zone refill/save reported 0 violations, 0 unconnected items, and 0 schematic parity issues. See [drc.json](drc.json). Schematic ERC reported 0 violations in [erc.json](../xiao-schematic/erc.json).
- **Geometry/netlist:** [geometry.json](geometry.json) records the final PCB checksum and every expected drill. All 36 switch footprints, 36 diodes, and original mechanical footprints retain their exact native positions, orientations, pad geometry, and nets. All 191 exported schematic terminals match the PCB. Specctra placement rounding was removed before this comparison. The board is 1.6 mm thick.
- **Gerber/drill parsing:** Gerbonara 1.6.3 independently opened the ZIP and checked seven graphic layers, separate plated/non-plated Excellon files, and a Gerber job file. All 215 plated drills and 148 non-plated holes/slots match the PCB within 0.002 mm. This includes 36 five-millimetre switch centres, 72 Choc V1 locators, and 36 Choc V2 1.5 × 2 mm slots. See [gerbers.json](gerbers.json).
- **Profile:** three closed contours were found: the outer perimeter, 22 × 28 mm R1 battery opening, and 3.7 × 4.15 mm XIAO battery-contact access opening. Board dimensions, including arc extrema and excluding the plotted line width, are **219.000032 × 96.106071 mm**. Use **219 × 96.11 mm** if a quote requires manual dimensions. The Gerber preview was visually inspected on both sides. The JLCPCB web upload/automatic preview has not been tested for this ZIP.
- **Case:** the CAD generator checks valid single solids, component-envelope clearance, all 36 switch-body envelopes, battery-pocket roof thickness, heat-set seats, and recessed tray fasteners. STEP reimport and STL watertightness checks also passed. See [case notes](../../xiao-case.md) for the assumed USB/module heights and required feet.
- **Firmware:** a clean ZMK build passed against pinned revision `5b51501fead672c41b5cfb396f3dafe0894bf4e9`, with the bundled shift-register interrupt patch. The UF2 SHA-256 is `897c32f8a1b893bbe501ab9a0d06c69f7789baa9a00c9becead28bae97b8d03e`. See [firmware notes](../../xiao-firmware.md).

The checks can be repeated using `tools/verify_xiao_pcb.py` with KiCad's pcbnew Python and an XML netlist exported from the final schematic, then `tools/verify_xiao_gerbers.py` with Gerbonara. `tools/export_jlcpcb.py` regenerates the manufacturing ZIP from the saved PCB. Its output directory must be new. `tools/build_xiao_pcb.py` is a placement/routing starting-point generator, not a regeneration of the finished hand-reviewed PCB; use a scratch output path.

Physical prototype tests remain: switch and socket fit, USB plug clearance, battery dimensions and retention, insulation/strain relief, both XIAO underside jumpers, all keys/rollover, Bluetooth range/pairing, idle/sleep/wake behavior, battery sensing, and the intended approximately 50 mA charging current. These checks cannot establish enclosure fit or electrical/RF performance without assembled hardware.
