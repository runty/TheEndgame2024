# Endgame updates — 2026-10-15

## nice!nano case correction

The previous inner-thumb fill left missing roof material and a step nearly 1 mm
deep. Both areas now use the pristine original case surface, translated with
the widened key halves. The original slope and rounded opening edges continue
smoothly across the repair. See the [before/after comparison](../002%20CASE/NICE%20NANO%20WIRELESS/thumb-roof-repair-preview.png).

The generator checks 8,990 roof points against the original, including the repair
boundaries. The STEP is a valid single solid and the STL is watertight. Existing
plates retain 0.2 mm clearance; the battery recess and 15 mm USB opening remain.
Use the updated [case STL](../002%20CASE/NICE%20NANO%20WIRELESS/TheENDGAME2024_NICE_NANO_CASE.stl).
The case is still 231 mm wide and is required for the nice!nano PCB; the original
Endgame case does not fit. The new print has not yet been physically checked.

## Choc V2 thumb-cap sets

The [keycap package](../006%20KEYCAPS/CHOC%20V2%20THUMBS/) includes sculpted Chicago
Steno and convex profiles, each as a connected 2 × 3 set of four long and two
small caps. Both use MX-style Choc V2 sockets. Individual caps, parametric
source, licences, preview images, and validation reports are included in the
[ZIP](../006%20KEYCAPS/Endgame_ChocV2_Thumb_Keycaps.zip).

Both grids are single connected, watertight meshes. Actual socket fit, print
strength, and JLC3DP acceptance remain untested; ordering notes are in the package.

## Philyoku firmware and Bluetooth

The [current UF2](../003%20FIRMWARE/zmk-endgame-nice-nano/firmware/endgame-nice-nano-philyoku-6profiles.uf2)
adds a sixth saved Bluetooth profile and extends battery/connection flashes to
500 ms, with 250 ms between queued indications. On the BT layer, the left top
row selects profiles 1–5 and the innermost right top-row key selects profile 6.
The selected profile receives typing; the existing clear-profile key clears it.

Normal flashing is expected to retain the existing five pairings. Their indices
remain 0–4; the new slot is 5. Do not use settings-reset firmware or `BT_CLR` when
preserving bonds. The build passed locally and its generated settings/keymap
were checked; six-profile hardware pairing has not been tested.

Source of truth: [zmk-keyboards Endgame target](https://github.com/runty/zmk-keyboards/tree/codex/endgame-nice-nano/keyboards/endgame-nice-nano)
and [Philyoku](https://github.com/runty/philyoku/tree/codex/endgame-nice-nano).
The hardware repository also retains its original QWERTY firmware separately;
that older image has 120 ms flashes. See the [firmware notes](nice-nano-firmware.md).

## User assembly feedback

The LED was reported working without C1 fitted. This is a functional observation,
not validation over all supply conditions; the 100 nF capacitor remains in the BOM.
No PCB or Gerber changes were required for these case, keycap, or firmware updates.
